# AI Instructions

Welcome to the BitNode-Console project! This file provides basic guidelines for using AI in this repository.

## General Guidelines
- Use AI to generate code, documentation, and tests where appropriate.
- Review all AI suggestions for accuracy, security, and style before committing.
- Follow the project's coding standards and best practices.

## Contribution
- Ensure AI-generated code is clear and maintainable.
- Add comments to clarify complex logic.
- Avoid committing sensitive or proprietary information suggested by AI.
